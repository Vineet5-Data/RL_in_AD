## 3. Threat Assessment

**No paper covers 3+ pillars simultaneously in the GPS map-matching domain.**

### START (2023) — P1a + P1b(partial) + P3
- Covers: BERT-style Transformer (P1a) + GAT road encoder with traffic/visit-frequency semantics (P1b partial) + span-masked recovery + contrastive objectives (P3)
- Missing: Not a map-matching system — produces trajectory embeddings, never assigns GPS to road segments. No RL of any kind. P1b is partial (visit-frequency statistics, not road-type/POI/topology tokens).
- **Verdict: NOT A THREAT**

### Semantic-Enhanced Road Network / Toast-DyToast (2024/2025) — P1a + P1b(partial) + P3
- Covers: Transformer pretraining (P1a) + traffic-context semantic prediction (P1b partial) + self-supervised objectives (P3)
- Missing: No map-matching decision step. No RL, no latent world model (P2 fully absent). P1b partial (traffic speed/context, not KG-derived road attributes or POI embeddings).
- **Verdict: NOT A THREAT**

### RLOMM (2025) — most recent RL map-matching paper
- Covers: Sequential RL decisions over candidate road segments (superficially overlaps P2), GNN+RNN encoders
- Why not P2: RL decisions over an explicit MDP with enumerated candidates and hand-designed rewards — fundamentally different from acting inside a learned latent simulation. "Latent space" is GNN embedding for scoring, not a world-model that predicts next-state distributions. Also requires supervised ground-truth matched paths.
- **Verdict: NOT A THREAT** (fixed anchor: adjacent-but-distinct)

### MIDIRL (2024) — deep IRL map matching
- Uses max-entropy deep IRL (surface similarity to P3 label-free). However: IRL requires correct demonstration routes (labeled data); MDP state is hand-engineered feature vectors; no learned world model.
- **Verdict: NOT A THREAT** (fixed anchor: adjacent-but-distinct)

### Think2Drive (2024) — only true latent-world-model RL paper
- Covers P2 architecturally (DreamerV3-style compact world model). However: domain is CARLA-v2 simulation, BEV/sensor observations, low-level control outputs. Never processes GPS, never assigns points to road segments. P1a, P1b, P3 absent in map-matching sense.
- **Verdict: NOT A THREAT** (fixed anchor: adjacent-but-distinct)

## 4. Key Insights

### Argument 1: P2 is an absolute firewall in the map-matching domain
Every GPS map-matching paper uses HMM/Viterbi, one-shot seq2seq, or RL over explicit candidate-segment MDPs with hand-crafted rewards. None uses a learned compressed latent simulation as the training environment. Think2Drive proves the architecture exists; the transfer to GPS map matching is genuinely novel.

### Argument 2: Nearest multi-pillar neighbors are representation-only frameworks
START and Semantic-Enhanced Road Network reach P1a + P1b(partial) + P3 but produce no road-segment assignment. The thesis closes the distance from "pretraining a semantic encoder over road graphs" to "using that encoder inside a latent-RL agent for GPS-to-road assignment."

### Argument 3: P1b is bifurcated — symbolic vs. learned
- Ayara lineage: symbolic (OWL/RDF, Datalog, SPARQL)
- RouteKG: KG-completion sense
- START/Semantic-Enhanced: traffic-statistics sense
- None: learned vectorization sense (road-type + POI + functional topology as learned graph tokens in a map-matching context)

### Argument 4: 2025 Survey independently confirms gap
Waksmundzki et al. (2025) frames a unified learned framework as an *open research direction*, not existing work — independent confirmation the P1a + P1b + P2 + P3 combination is unoccupied.

### Literature Topology Around the Gap

```
Representation cluster  →  P1a + P3, P1b(partial) — never assigns GPS to road
RL map-matching cluster →  explicit-candidate MDP, supervised — no latent world model
AD inspiration cluster  →  proves P1b, P1a, P2 exist (Think2Drive) — wrong domain
Ayara lineage           →  symbolic P1b, zero neural components
Classical baseline      →  HMM (Newson-Krumm 2009)
─────────────────────────────────────────────────────────────
CENTER (unoccupied)     →  P1a + P1b + P2 + P3
```

The gap is not incremental — it spans a qualitative architectural jump (seq2seq → latent-world-model RL) that no map-matching paper has crossed.
